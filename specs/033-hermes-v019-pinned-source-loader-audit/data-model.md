# Spec033 Data Model

`SourceBundleDecision` and `LoaderAuditDecision` are exact-class, sealed factory-issued immutable values. Weak-reference provenance registries bind each decision to a per-instance identity token and sealed primitive/tuple fields; paired loader decisions are bound by exact bundle identity. Issuance accepts only a closed factual vocabulary, and receipt projection re-derives current canonical source evidence before accepting a pair, so Python introspection cannot authorize hostile or stale facts. Every decision fixes `runtime_status` to `not_run` and `live_actions_authorized` to `false`.

`SourceBundleDecision` contains only validation booleans and pinned project provenance. `LoaderAuditDecision` contains bounded graph and capability-order statuses, including separately modeled import-time and call-time callers. The public receipt has a fixed safe keyset and rejects forged, copied, subclassed, mutated, hostile, stale, or mismatched values without returning source bytes, local paths, URLs, exception messages, or credential-like values.

`reviewed-artifact-manifest.json` hashes reviewed implementation, tests, specifications, pinned-source artifacts, and the final verifier. It intentionally excludes only itself and `review-root.json` to avoid a self-hash cycle. `review-root.json` binds the manifest digest. Required reviews record that detached root identity; the final verifier verifies the reviewed artifacts before and after focused tests and emits the current `review_root_sha256` so Main can compare the one-run receipt with the reviewed root without keeping a mutable self-held digest literal.
