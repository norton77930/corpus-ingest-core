# Data model

Safe evidence uses closed scenario IDs, canonical tool names, exact booleans, capped counts, policy-block status, `action_next`, and `raw_persisted=false`. S019's episode reference is transient validation input and never projected. The owner-only ledger is factory-only and identity-bound before evidence can mark it present; it has no prompt, response, payload, config bytes/digest, credential, or session ID.
