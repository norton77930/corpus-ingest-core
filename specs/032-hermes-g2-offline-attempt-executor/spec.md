# Spec 032: Hermes G2 offline attempt executor

## Scope

A successor-owned offline state machine provides: blocked production source gate; factory-sealed offline approval and approval-bound single-use lease; factory-issued in-memory single-process ledger with lock-protected absent-only claim and single-winner terminalization; exact synthetic-driver executor; closed operation/metadata parser; safe actual-result receipt; and future-only static adapter/runner declarations.

## Truthfulness

The pinned-source proof available in this repository cannot establish an official provider-free loader call path. Therefore production evaluation is exactly `BLOCKED_CREDENTIAL_SEAM`, with no lease, ledger, or driver call. `PASS_OFFLINE_EXECUTOR_CONTRACT` means only synthetic fake-driver/temp-ledger execution passed. `LIVE_H4_ONE_RUN` is declared but has no issuer here; live actions are unauthorized.

## Non-goals

No Docker, Compose, Hermes, MCP/Core/provider execution, C6, production marker creation, credential/config/session/log/raw-response access, or Spec026–031 modification.
